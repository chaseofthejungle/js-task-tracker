# JS Task Tracker
  
**Description:** Organizes in progress and completed tasks into lists. Tasks may be added or renamed using a button or the Enter key, and may be deleted by clicking a delete button. Completed tasks may be returned to the in progress tasks list. Compatible with all popular web browsers.
  
**Live Demo:** [Click Here](https://chaseofthejungle.github.io/js-task-tracker/app/)
